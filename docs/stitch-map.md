## Repeated component candidates

- **Site shell:** `SiteHeader`/navigation, logo treatment, and `SiteFooter` across all page routes.
- **Page framing:** breadcrumbs, section headings/eyebrows, page hero variants, and reusable CTA sections.
- **Listings:** a shared card shell with distinct `BusinessListingCard`, `CommercialPropertyCard`, and `FranchiseOpportunityCard` content variants.
- **Search and filtering:** desktop `FilterSidebar` plus a mobile `Sheet`/drawer variant for business and commercial listings.
- **Lead capture:** shared form field/error/consent primitives, with separate forms and validation for contact, seller valuation, acquisition criteria, CIM access, franchise strategy, property inquiry, and investor consultation.
- **Data presentation:** financial/operational metric grids, confidentiality/status badges, and recent-transaction tiles.
- **Editorial content:** `TeamMemberCard` and service-area/location sections.

## Homepage design context and token comparison

The Stitch design markdown describes an intended brand palette that partly matches the requested values, while its generated `designTheme`/homepage HTML contains several conflicting rendered colors. The homepage implementation uses the requested brand palette as named CSS/Tailwind tokens; conflicting rendered Stitch colors were not silently adopted.

| Requested token     | Stitch design notes                                             | Stitch theme / homepage values                                                                     | Finding                                                                                             |
| ------------------- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Navy `#0F172A`      | Matches the stated primary role and custom color.               | `primary` is `#000000`; `on_surface` is `#0B1C30`; `primary_container` is `#131B2E`.               | Implemented as the primary brand token.                                                             |
| Gold `#D97706`      | Matches the stated tertiary role.                               | `tertiary` is `#000000`; `on_tertiary_container` is `#C76C00`; `secondary_container` is `#FD8A42`. | Implemented as the gold accent token; not used for small text on light backgrounds due to contrast. |
| Bronze `#B45309`    | Matches the stated secondary role.                              | `secondary` is `#9B4500`.                                                                          | Implemented as the bronze accent token, including readable accent text and CTA backgrounds.         |
| Slate `#475569`     | Not used as the design-system neutral; notes specify `#64748B`. | `on_surface_variant` is `#45464D`.                                                                 | Implemented as the muted text token.                                                                |
| Off-white `#F8FAFC` | Included as a canvas foundation.                                | `background`/`surface` is `#F8F9FF`.                                                               | Implemented as the page canvas token.                                                               |
| Border `#E2E8F0`    | Matches the stated border/divider role.                         | `outline_variant` is `#C6C6CD`.                                                                    | Implemented as the border/divider token.                                                            |

**Typography:** Stitch specifies Space Grotesk for headings and Manrope for body/labels. The homepage uses those families; Geist Mono remains available for code-like content.

**Spacing:** Stitch specifies spacing values of `0.25rem`, `0.5rem`, `1rem`, `1.5rem`, `2.5rem`, and `4rem`; desktop gutters of `1.5–2rem`; and a desktop outer margin of `4rem` (with smaller tablet/mobile margins). The responsive implementation uses Tailwind's spacing scale with narrower mobile gutters.

## Implementation status

- The homepage shared components are in `src/components/`, with page sections and demo content in `src/features/home/`.
- The mobile header drawer, sticky quick-action bar, and responsive section layouts are implemented; the Stitch project has no separate mobile screen.
- Prisma `BusinessListing` is defined in `prisma/schema.prisma`. A migration and illustrative seed script are included, but the migration and seed have not been applied to a database.
- Featured opportunities are loaded by a cached Prisma server function tagged `featured-listings`. `HOMEPAGE_DESIGN_PREVIEW=true` explicitly enables the shared illustrative seed fixtures for visual QA; normal requests use Prisma. Closings and testimonials remain labeled illustrative demo content.
- `/businesses-for-sale` now uses URL-backed filters, Prisma-backed active listings, server-persisted saved searches and buyer criteria, plus loading/error/empty states. Its Stitch screen has no mobile variant; the page adapts responsively. `BUSINESS_LISTINGS_DESIGN_PREVIEW=true` explicitly enables illustrative public-only cards for visual QA; normal requests always use Prisma.
- `/businesses/[slug]` uses an explicit public-only Prisma projection, the shared listing card and buyer-criteria form, and responsive loading/error/not-found states. The Stitch screen has no mobile variant; gated financial, identity, and operating details are withheld until a future verified NDA workflow exists. Its remote placeholder photos are not used because the repository has no listing media.
- `/sell-a-business` uses shared site/section/FAQ/CTA components, a responsive local waterfront hero, five process steps, a seller-vs-advisor comparison, staged-disclosure guidance, and two Zod-validated Server Action forms persisted to `SellerValuationRequest`. - `/commercial-real-estate` uses the shared site shell, responsive category cards, URL-backed `nuqs` search and filters, Prisma-backed public property summaries, and an accessible Zod-validated Server Action inquiry form. `COMMERCIAL_PROPERTY_DESIGN_PREVIEW=true` explicitly enables clearly labeled illustrative cards for visual QA; normal requests always use Prisma. Franchise identity and financial details are omitted; the page includes franchisor-approval, lender-approval, and professional-advice disclaimers. No dedicated Stitch mobile variant exists; the page adapts responsively.
- `/investor-visas` uses the shared site shell and local waterfront image, general E-2, EB-5, and L-1A overviews linked to USCIS, an acquisition process section, and a Zod-validated Server Action inquiry persisted to `InvestorVisaConsultationRequest`.
